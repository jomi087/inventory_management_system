# Inventory Management System (IMS)

## 📌 Overview
This is a **Full Stack Mini Project** built to give an **overall, broad idea of how an Inventory Management System (IMS) looks and works**.

---

## 🏗 Tech Stack

### Frontend
- **React**
- **TypeScript**

### Backend
- **Express**
- **TypeScript**
- **Repository Architecture**
- Service Layer
- Dependency Injection (DI)

### Database
- **MongoDB**

---

## 🌐 Deployed URLs
- **Frontend (Live):** https://ims.shop  
- **Backend API:** https://api.ims.shop

---

## 🎯 Purpose of This Project
This mini project is intended for:
- Learning full-stack application structure
- Understanding backend architecture patterns
- Getting hands-on experience with 
  - React
  - TypeScript
  - MongoDB
  - Understanding how an IMS is designed and implemented
---
